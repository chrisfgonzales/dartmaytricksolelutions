# Dot Matrix Solutions — GitHub Pages SPA

Buildless HTML, CSS, and JavaScript. No package installation, API key, framework, external fonts, or CDN scripts. Open index.html directly to preview; clipboard copying may require HTTPS, with a download fallback.

## Publish
1. Keep a backup or commit of your existing site.
2. Copy index.html, CNAME, and .nojekyll from this package into the root of your existing GitHub Pages publishing branch. Replace the previous index.html.
3. Commit and push to that branch. Keep your existing Pages configuration and DNS records.
4. If your Pages source is /docs instead, place those three files in /docs.
5. Verify the deployed domain and navigation after the Pages deployment completes.

CNAME contains dotmatrixsolutions.com. Remove it for a preview repository that must not claim your production domain. Do not change production DNS for this source update.

## What changed
- Retained dark cyan/violet styling with responsive, dependency-free CSS.
- Replaced fabricated metrics, unverified testimonials and client claims with clearly labeled scope examples.
- Replaced simulated Airo generation with a transparent guided planner.
- Replaced the non-sending inquiry form with downloadable/copyable project briefs and the existing DMS GoDaddy Pro profile link. No message is sent automatically.
- Replaced unsupported price and delivery promises with an interactive scope checklist.
- Added semantic sections, keyboard navigation, large controls, reduced-motion support, larger text, focus indicators, and a skip link. This is not a formal WCAG certification.
- Distinguished an independent GoDaddy affiliate relationship from a live Airo integration.

## Editing
Everything is in index.html. Colors are in :root; suggested discussion points are in the plans object. The primary contact destination is https://experts.godaddy.com/dotmatrixsolutions. Confirm that this profile provides your preferred current contact method before publishing. To use an email CTA instead, replace that link with your verified mailto address; none was invented for this package.

## Behavior and privacy
Planner text is rendered with textContent, never interpreted as HTML. Entries remain in memory only. There is no backend, analytics, form delivery, live AI, domain registration, or payment processing. Preference switches last for the current visit. The hosting provider and external profile have their own privacy practices.

## Validation
JavaScript syntax, local references, fragment targets and HTML structure were checked during preparation. Browser visual QA was not performed. Before committing, open on your phone, create/download a brief, adjust scope, filter examples, and verify your contact profile.
